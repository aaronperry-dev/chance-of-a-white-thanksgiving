      About this map

      Map. A grid of roughly 0.6-mile cells in NOAA’s projection (North America Lambert Conformal Conic, ESRI:102009), drawn in NOAA’s colour ramp with eight classes spread over the Thanksgiving range. NOAA publishes the station values but no grid, so the surface is estimated from them using a terrain-aware method. Terrain relief is a hillshade of that elevation data. The estimate is a model between stations, not a measurement; where stations are sparse, mountains in particular, it can be off by more.

      Stations. Dots, search and the station table use the station values from NOAA NCEI’s daily Climate Normals, element DLY-SNWD-PCTALL-GE001WI (source · stations.csv). Thanksgiving is the fourth Thursday of November, so it can fall on any date from Nov 22 to Nov 28; the map shows the average of those seven dates (the daily values differ by only a point or two at most stations). Climatology is not a forecast; check weather.gov within a week of the holiday.
